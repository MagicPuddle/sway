About This Repository

This repository contains configuration files for setting up the Sway Window Manager with a MagicPuddle theme, providing a sleek, modern, and fully functional environment.

Sample Configuration

# Sway Window Manager config for MagicPuddle OS

# General Settings
output * resolution 1920x1080
font pango:Arial 10

# Keybinds
bindsym $mod+Return exec alacritty
bindsym $mod+d exec dmenu_run
bindsym $mod+Shift+q kill

# Workspaces
set $ws1 "1"
workspace $ws1
